# 绍兴滨海新区国投集团农田数字化管理系统

## 建设内容需求分析与系统设计文档包

本目录基于招标文件《定稿：绍兴滨海新区国投集团农田数字化管理.pdf》整理，供需求确认、原型设计、软件开发、设备集成、投标技术文件编制及演示视频录制使用。

## 文档目录

1. [需求分析与总体设计](./01-需求分析与总体设计.md)
   - 项目背景、目标、范围与边界
   - 用户角色与业务场景
   - 软件、硬件、云服务及安全建设要求
   - 业务流程、功能架构、数据架构、技术架构
   - 接口、权限、非功能、实施和验收设计
   - 全文用“【演示重点】”标出视频演示必须体现的功能

2. [演示重点与15分钟视频脚本](./02-演示重点与15分钟视频脚本.md)
   - 按评审评分点拆解演示目标
   - 演示数据准备方案
   - 逐分钟视频脚本、操作路径和解说词
   - 录制、封装、播放和应急检查清单

3. [需求追踪与建设任务矩阵](./03-需求追踪与建设任务矩阵.md)
   - 招标条款到功能模块、数据、接口、设备、演示和验收的映射
   - 优先级、责任边界、交付物及验收证据
   - 当前需要向采购人确认的资料和接口清单

## 使用说明

- “必须”表示招标文件明确提出或直接影响验收/评分的要求。
- “建议”表示为保证可用性、可维护性和演示效果提出的设计方案，正式投标时应结合实际报价和实施能力确认。
- “【演示重点】”表示应在不超过 15 分钟的录制视频中明确展示；同一功能在主文档、脚本和追踪矩阵中保持一致。
- 设备具体品牌、型号、检测报告、软件著作权和原厂证明材料，应以最终投标响应为准，不能仅以本设计文档替代。
