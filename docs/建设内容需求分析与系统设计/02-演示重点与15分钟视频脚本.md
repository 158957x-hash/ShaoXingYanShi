# 15分钟演示重点与视频脚本

## 1. 演示目标

本视频用于招标评审，演示时间不超过 15 分钟。评分重点对应第五部分“视频演示”中的六类能力：

1. 档案管理能力；
2. 筛选、查询和统计分析；
3. 空间关联联动；
4. 合同三色预警；
5. 渣土告警可视化；
6. 综合平台能力和系统闭环。

前五项必须清晰完整，其他系统能力用于体现整体建设能力，不能挤占核心评分点时间。

## 2. 演示原则

- 采用一个真实感强的业务案例贯穿全程：例如“滨海新区江滨农场—某流转大户—某地块—水稻—合同即将到期—关联视频—巡检告警”。
- 所有操作使用预置演示账号和演示数据，避免现场录入过多文字。
- 每个评分点都要出现“动作—结果—业务价值”。
- 页面顶部显示当前模块名称，解说明确说明对应招标要求。
- 所有数据采用一致的主体、地块、合同和设备编号。
- 视频必须能离线播放，不能依赖评审现场访问外部系统。

## 3. 演示数据准备

### 3.1 基础数据

建议准备以下最小数据集：

| 数据 | 数量建议 | 说明 |
|---|---:|---|
| 行政区域 | 3-5 个 | 用于区域筛选 |
| 流转大户 | 8-12 户 | 覆盖正常、黄色、红色合同 |
| 地块图斑 | 15-30 个 | 至少 1 户关联多个地块 |
| 合同 | 10-15 份 | 正常、即将到期、已到期、履约异常 |
| 作物 | 4-6 类 | 水稻、蔬菜、瓜果等 |
| 摄像头 | 6-10 个演示点位 | 至少 1 个地块关联多个摄像头 |
| 电表 | 6-10 个 | 正常、催缴、断电 |
| 渣土告警 | 6-10 条 | 本周、本月、本年统计均有数据 |
| 气象预警 | 1-2 条 | 台风/暴雨等 |
| 合同扫描件 | 3-5 份 | 用于在线预览 |
| 抓拍图片 | 6-10 张 | 清晰、带时间和位置 |

### 3.2 必须预置的关键样例

| 样例 | 预置状态 | 演示用途 |
|---|---|---|
| 大户 A | 正常合同，绿色 | 对比正常状态 |
| 大户 B | 60 天到期，黄色 | 到期提醒 |
| 大户 C | 15 天到期，红色 | 高危预警 |
| 地块 P001 | 关联大户 B、合同 B、摄像头 C001/C002 | 地图联动 |
| 电表 E001 | 余额 80 元，绿色 | 正常用电 |
| 电表 E002 | 余额 20 元，黄色 | 催缴 |
| 电表 E003 | 欠费断电，红色 | 高危用电 |
| 告警 G001 | 本周 1 次，黄色区域 | 渣土三色 |
| 告警 G002 | 本月多次，红色区域 | 渣土高风险 |

## 4. 逐分钟演示脚本

### 0:00-0:30｜项目驾驶舱开场

**画面动作**

- 进入驾驶舱首页；
- 展示总流转户数、总流转面积、主栽作物、合同风险、用电风险和巡检告警；
- 鼠标停留在“合同预警”和“渣土告警”指标卡片。

**解说建议**

> 本系统面向约 1.8 万亩农田，围绕流转主体、地块、合同和智能设备构建统一的数字化管理平台，通过一张图和告警中心实现农田管理、风险监管和现场处置闭环。

**重点标记**：展示整体理解和综合能力；时间必须控制在 30 秒内。

### 0:30-3:00｜档案管理和 Excel 导入导出【P0，评分重点】

**画面动作**

1. 进入“流转大户管理”；
2. 点击“导入模板”，展示字段：姓名、联系方式、行政区域、合同编号、合同签订时间、合同到期时间、流转面积、种植作物、经营主体性质；
3. 选择演示 Excel 文件并导入；
4. 展示导入结果：成功数、失败数、失败原因；
5. 打开新导入的大户档案；
6. 展示该大户下的合同、地块、作物、设备和告警摘要；
7. 按当前条件导出 Excel。

**解说建议**

> 系统支持流转大户数字化建档，实现一户一档。档案字段覆盖主体、合同、面积、作物和经营性质，并支持 Excel 批量导入、导入校验、错误反馈和按筛选结果导出。

**必须让评委看到**

- 字段完整；
- 导入确实产生数据；
- 档案详情不是空页面；
- 合同、地块和作物已经形成关联；
- 导出按钮和结果明确可见。

### 3:00-5:30｜筛选、查询、统计分析【P0，评分重点】

**画面动作**

1. 在档案列表选择行政区域；
2. 选择作物类型；
3. 选择合同状态“即将到期”；
4. 设置流转面积区间；
5. 点击查询；
6. 再用农户姓名或作物关键词搜索；
7. 展示区域流转户数、总流转面积、作物分布、合同到期时段四类统计；
8. 点击统计图表反向筛选列表；
9. 导出统计报表。

**解说建议**

> 系统支持区域、作物类型、合同状态和面积区间的组合筛选，也支持按姓名和作物关键词查询。统计结果包括区域户数、流转面积、作物分布和合同到期时段，并可以导出 Excel 报表。

**演示注意**

- 筛选前后数量必须有变化；
- 统计图表必须与列表数据一致；
- 不要停留在只有图表没有数据的页面。

### 5:30-8:30｜农田一张图和空间联动【P0，评分重点】

**画面动作**

1. 进入“农田一张图”；
2. 输入农户姓名或地块编号；
3. 地图自动定位到目标地块；
4. 点击图斑；
5. 展示右侧详情：地块编号、面积、农户、合同、作物和合同状态；
6. 点击合同卡片查看合同详情或扫描件；
7. 点击关联视频，打开对应摄像头；
8. 点击告警/设备标签，查看关联事件。

**解说建议**

> 系统以地块图斑作为业务关联中心，将流转主体、种植信息、合同状态和监控设备绑定。用户可以按农户或地块检索，地图自动定位，点击图斑即可查看全部关联信息，实现以图管地、以地管人。

**必须让评委看到**

- 搜索后地图真的移动或定位；
- 图斑点击后显示完整业务信息；
- 至少打开一次关联视频或告警；
- 地图颜色与合同/告警状态一致。

### 8:30-10:30｜合同三色预警【P0，评分重点】

**画面动作**

1. 进入“合同监管”；
2. 展示正常、黄色提醒和红色预警三类合同；
3. 展示合同剩余天数、履约状态、总金额、已纳金额和待缴金额；
4. 点击红色合同查看合同详情和原件扫描件；
5. 返回驾驶舱，展示红色/黄色数量变化；
6. 返回地图，展示地块颜色/预警图标变化；
7. 展示按预警等级和区域筛选。

**解说建议**

> 系统默认按照剩余有效期和履约状态实施三色预警：超过 90 天为绿色，不超过 90 天且超过 30 天为黄色，不超过 30 天或已逾期为红色。预警结果同步到驾驶舱和农田一张图，并支持按等级、区域和时间查询。

**演示注意**

- 三种颜色必须同时出现；
- 说明阈值可配置；
- 要展示“列表—驾驶舱—地图”至少两个位置同步。

### 10:30-13:00｜渣土告警可视化【P0，评分重点】

**画面动作**

1. 进入“无人机巡检/告警中心”；
2. 展示本周、本月、本年事件统计；
3. 在地图点击一个告警点；
4. 打开告警详情：位置、识别时间、事件等级和抓拍图片；
5. 放大抓拍图片；
6. 展示绿色、黄色、红色区域分布；
7. 点击一条告警，执行确认/转派/关闭中的一种操作；
8. 展示处置记录。

**解说建议**

> 系统接入无人机夜间巡检和渣土倾倒 AI 识别结果，告警包含位置、时间和现场抓拍图片。平台按本周、本月、本年统计，并按照未发生、每周发生一次及以上、超过三次分别以绿、黄、红进行区域管理。

**必须让评委看到**

- 时间统计；
- 地图告警点；
- 图片查看和放大；
- 三色区域；
- 至少一次告警处置闭环。

### 13:00-14:30｜综合能力展示【P1】

依次快速展示，不深入操作：

1. 智能电表：正常、催缴、断电三色状态；
2. 视频监控：地块关联实时视频；
3. 无人机：机场状态、任务状态或直播画面；
4. 气象预警：台风/暴雨风险卡片和影响范围；
5. 应急广播：选择区域、文字转语音、操作确认；
6. 溯源二维码：扫码查看地块、作物和种植批次。

每项不超过 15 秒，避免因切换过多导致视频失焦。

### 14:30-15:00｜总结收尾

**画面动作**

- 回到驾驶舱；
- 依次指向“档案、地图、合同、告警”四个入口；
- 显示项目建设价值。

**解说建议**

> 通过一户一档掌握流转主体，通过农田一张图关联地块，通过合同和用电预警提前发现风险，通过无人机、视频、气象和广播实现现场监管和应急响应，最终形成数据采集、风险识别、告警处置和统计分析的农田数字化管理闭环。

## 5. 录制前检查清单

### 5.1 数据和页面

- [ ] 所有演示账号可以正常登录；
- [ ] 首页指标与业务列表数据一致；
- [ ] Excel 文件路径固定且可访问；
- [ ] 导入结果、导出文件和统计结果均已验证；
- [ ] 地图图斑正常显示；
- [ ] 地图定位、图斑弹窗和详情联动正常；
- [ ] 视频、图片、合同扫描件均可打开；
- [ ] 合同三色状态至少各有一条；
- [ ] 渣土告警三色区域和抓拍图片完整；
- [ ] 电表、气象、无人机和广播有可展示的模拟或真实数据。

### 5.2 技术和画面

- [ ] 录制分辨率不低于 1920×1080；
- [ ] 视频比例 16:9；
- [ ] 编码优先使用 H.264，确保兼容性；
- [ ] 字体、鼠标指针和操作区域清晰可见；
- [ ] 关闭无关通知、弹窗和浏览器标签；
- [ ] 录制前清空无关测试数据；
- [ ] 关闭自动更新、屏保和系统休眠；
- [ ] 全流程实际时长控制在 14 分 30 秒以内；
- [ ] 视频结尾不要出现桌面、命令行或个人信息。
