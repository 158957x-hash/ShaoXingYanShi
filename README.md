# 绍兴滨海新区农田数字化管理平台演示原型

## 打开方式

推荐通过本地 HTTP 服务打开，避免浏览器限制本地 GeoJSON 的读取：

```powershell
python -m http.server 8765
```

然后打开：

```text
http://127.0.0.1:8765/index.html
```

也可以直接双击根目录的 `index.html`。页面已内嵌同一份 293 个地块和越城区边界数据，因此 `file://` 和 HTTP 方式打开时使用的矢量数据一致；HTTP 方式仍更适合加载天地图在线瓦片。

GitHub Pages 部署：推送到 `main` 后由 `.github/workflows/deploy-pages.yml` 自动发布。

## 已接入内容

- 项目行政区划：绍兴市越城区，滨海新区/江滨农场项目区；
- 行政区划开源数据：阿里云 DataV 行政区划 GeoJSON，已下载越城区本地回退文件 `assets/yuecheng-boundary.geojson`；
- 天地图：默认使用地形图（绿色、水系和地形表现），同时配置矢量、矢量注记、影像和影像注记图层，可通过地图上的“切换底图”循环切换；
- 地块矢量：使用用户提供的 `source/矢量文件/评价单元.shp`，共 293 个地块要素；
- 坐标处理：原始数据为 CGCS2000 3 度分带高斯投影、中央经线 111° 的海南区域数据。当前原型为演示用途，将地块拓扑按比例拟合到绍兴滨海新区项目展示范围，具体转换逻辑见 `scripts/convert_shp.py`。正式建设时应替换为采购人提供的绍兴项目区 CGCS2000/WGS84 地块数据；
- 外部资源不可用时：自动使用本地 SVG 地图、地块、行政区划边界和演示数据，核心演示流程不中断。

## 一级问题整改说明

- 档案管理：支持真实文件选择，CSV/Excel 导入校验、当前筛选结果导出，以及完整的一户一档详情字段；
- 筛选统计：档案支持区域、作物、合同状态、面积区间和关键词组合筛选，统计卡片随结果实时变化；合同支持区域、风险等级和履约状态筛选；
- 关系联动：统一维护主体、合同、地块、电表、摄像头和告警关系，支持合同定位地块、地块打开关联视频、电表定位地图；
- 合同预警：按到期日和欠费情况动态计算绿/黄/红状态，支持阈值配置、扫描件预览和台账导出；
- 渣土告警：支持本周/本月/本年切换、抓拍图片放大、地图点位详情、确认/转派/关闭和备注，区域三色统计由告警记录动态计算。

Excel 导入使用 SheetJS 浏览器组件；联网时可直接读取 `.xlsx`，无网络时仍可使用模板导出的 `.csv` 完成演示。

## 建议演示顺序

1. 综合驾驶舱；
2. 流转大户：Excel 导入、组合筛选、档案详情；
3. 农田一张图：搜索地块、点击图斑、查看关联主体/合同/视频；
4. 合同监管：绿色、黄色、红色三色预警；
5. 无人机巡检：渣土告警、地图点位、抓拍信息和三色区域；
6. 快速展示视频、电表、气象、广播和溯源。

## 重要文件

- `index.html`：入口页面；
- `config.js`：项目位置、天地图 Key、行政区划和数据源配置；
- `app.js`：页面、交互、演示数据和地图联动；
- `styles.css`：系统视觉样式；
- `assets/parcels.geojson`：转换后的 293 个地块 GeoJSON；
- `assets/yuecheng-boundary.geojson`：越城区行政区划本地回退数据；
- `assets/embedded-data.js`：供双击打开时使用的内嵌地块和行政区划数据；
- `scripts/convert_shp.py`：地块转换脚本。
